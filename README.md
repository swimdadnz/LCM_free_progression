v4.5 Long Course Metres (LCM) freestyle progression model
Trained on Dutch data with AU / NZ / US data for the higher end
Enter PBs and dates along with date of birth, then it predicts future times with probabilities
Has not incorporated significant datasets from SwimCloud after acquisition of data from top 559 high schoolers in the US, but this is not a representative sample anyway

This version is responsive to screen size and allows toggling between PB vs season best (that may be lower in some years based on typical progression)
